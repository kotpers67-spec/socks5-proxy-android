## Socks5 Proxy Android v1.2.1 (Hotfix)

### Исправления:
1. **Запуск при включенном стороннем VPN**:
   - Устранена проблема блокировки запуска при активном стороннем VPN (WireGuard, Amnezia, OpenVPN, V2rayNG).
2. **Автоматический подбор свободного порта (Auto-port fallback)**:
   - Большинство VPN-клиентов на Android по умолчанию занимают локальный порт `10808`. Теперь приложение при занятости порта автоматически находит свободный порт (`10809`, `10810`, `20808`) и успешно стартует без сбоя.
3. **Автоопределение активного VPN (`VpnDetector`)**:
   - При обнаружении запущенного стороннего VPN приложение автоматически выбирает режим «Без сброса VPN», чтобы трафик шел через VPN прямо в SOCKS5 без разрыва соединения.
4. **Актуализация портов в кнопках быстрого применения**:
   - Кнопка «Применить в Telegram в 1 клик» и кнопка копирования для браузера используют реальный фактически открытый порт.
5. **Чистый код**:
   - 100% чистый production-код без комментариев и TODO.
