## Socks5 Proxy Android v1.2.0

### Что нового в v1.2.0:
1. **Выбор приложений доступен во ВСЕХ режимах работы**:
   - Блок «Маршрутизация приложений» теперь доступен как в режиме «Системный VPN», так и в режиме «Без сброса VPN» (локальный прокси 127.0.0.1:10808).
   - Полноэкранный селектор с поиском по названию и пакету, фильтрами («Все», «Выбранные», «Пользовательские») и кнопками «Выбрать все» / «Снять все».
   - Выбранные приложения отображаются наглядными чипами прямо в главной карточке с возможностью быстрого удаления.
2. **Быстрая интеграция в 1 клик для режима «Без сброса VPN»**:
   - Кнопка **«Применить прокси в Telegram в 1 клик»** (автоматический запуск через Intent `tg://socks?server=127.0.0.1&port=...` с fallback на веб).
   - Кнопка **«Скопировать адрес для браузера (127.0.0.1:10808)»** с визуальным подтверждением копирования.
3. **Полное устранение сбоев (Zero-Crash Guard) для HyperOS / Android 14–15**:
   - Перехват `ForegroundServiceStartNotAllowedException` при возврате из системных диалогов.
   - Защита от зависаний сокетов и утечек дескрипторов (FD leak).
   - Корректная обработка остановки нативного hev-socks5 (`TProxyStopService`) без системных крашей.
   - Поддержка `cancelChildren()` для многократных перезапусков локального сокета без перезапуска приложения.
4. **Чистый production-код**:
   - 100% чистый код без комментариев, заметок и TODO.
