# Socks5 Proxy Android

<p align="center">
  <b>Android-клиент локального SOCKS5, системного SOCKS-туннеля и VPN-профилей Xray.</b>
</p>

---

## Особенности и возможности

- **Три режима**: локальный SOCKS5 на `127.0.0.1` (сохраняет активное VPN), системный TUN через SOCKS5 и встроенный Xray VPN.
- **VPN-профили**: импорт узла или HTTPS-подписки со ссылками VLESS, VMess, Trojan, Shadowsocks, SOCKS и Hysteria2. Также разбираются старые VMess-ссылки формата Base64 JSON. Clash/Mihomo подписки не поддерживаются.
- **Цепочка VPN → SOCKS5**: трафик приложений сначала идет через выбранный Xray-узел, а затем через выбранный SOCKS5-сервер.
- **Выбор приложений**: системный и встроенный VPN-режимы могут направлять только выбранные приложения.
- **Нативный SOCKS-туннель**: `hev-socks5-tunnel`, поддержка архитектур `arm64-v8a`, `armeabi-v7a`, `x86_64`, `x86`.
- **Поддержка аутентификации**: Работа без авторизации или с логином и паролем (RFC 1928 / RFC 1929).
- **Релей UDP**: Передача UDP через SOCKS-туннель и поддержку UDP протоколами Xray в пределах возможностей выбранного сервера.
- **Встроенный диагностический пинг-тестер**: Прямая проверка SOCKS5-рукопожатия из приложения с замером точной задержки (RTT) в миллисекундах.
- **Удобный выбор приложений**: Поиск установленных приложений по названию и пакету, фильтры «Все» / «Выбранные», быстрые кнопки «Выбрать все» / «Снять».
- **Статистика Xray**: Встроенное ядро публикует счётчики соединений для отображения входящего и исходящего трафика.
- **Энергоэффективность и стабильность**: Оптимальный MTU 1400 (предотвращает фрагментацию и зависания пакетов в сетях 4G/5G LTE), адаптивный опрос статистики трафика и отсутствие утечек памяти при скролле списков.
- **Современный интерфейс**: Jetpack Compose, Material 3, швейцарский чистый дизайн, соответствие стандартам доступности **WCAG 2.2 AAA** и поддержка TalkBack.

---

## Архитектура проекта

- **Язык**: Kotlin 2.2 + C (JNI)
- **UI**: Jetpack Compose (Material 3)
- **Архитектура**: MVVM + Unidirectional Data Flow (StateFlow / Coroutines)
- **Сетевые движки**: `VpnService` + `com.zaneschepke:hevtunnel` для SOCKS5 и `libXray` для VPN-профилей
- **Минимальная версия Android**: Android 8.0 (API 26+)
- **Целевая версия Android**: Android 15 (API 35) / Android 16 (API 36)

### Ограничения VPN

Android допускает только один активный VPN-интерфейс для пользователя. Для запуска системного или встроенного VPN отключите другое VPN-приложение; приложение предупредит об этом и не заменит его незаметно. Режим локального SOCKS5 не занимает VPN-интерфейс и оставляет другое VPN подключенным. Встроенный Xray использует импортированный профиль и не включает чужие настройки маршрутизации/правила целиком.

## Установка

Скачайте скомпилированный APK из раздела [Releases](https://github.com/kotpers67-spec/socks5-proxy-android/releases) и установите его на Android-устройство:

```bash
adb install -r Socks5Proxy.apk
```

---

## Сборка из исходников

```bash
# Клонирование репозитория
git clone https://github.com/kotpers67-spec/socks5-proxy-android.git
cd socks5-proxy-android

# Сборка Debug APK
./gradlew assembleDebug

# Готовый универсальный APK будет расположен в:
# app/build/outputs/apk/debug/app-debug.apk
# Чтобы собрать меньший APK только для ARM64 телефона:
# ./gradlew -PtargetAbis=arm64-v8a assembleDebug
```
