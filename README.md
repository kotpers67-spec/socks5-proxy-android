# Socks5 Proxy Android

<p align="center">
  <b>Высокопроизводительный Android-клиент SOCKS5 прокси с выборочной маршрутизацией (Split-Tunneling) на базе Kotlin, Jetpack Compose и нативного ядра hev-socks5-tunnel.</b>
</p>

---

## Особенности и возможности

- **Выборочная маршрутизация (Split-Tunneling)**: Проксирование сетевого трафика только для выбранных приложений. Весь остальной сетевой трафик устройства идет напрямую, не создавая конфликтов и не сбрасывая сторонние соединения.
- **Нативное ядро C (`hev-socks5-tunnel`)**: Экстремальная скорость передачи данных без промежуточных накладных расходов виртуальной машины, поддержка архитектур `arm64-v8a`, `armeabi-v7a`, `x86_64`, `x86`.
- **Поддержка аутентификации**: Работа без авторизации или с логином и паролем (RFC 1928 / RFC 1929).
- **Релей UDP**: Полная поддержка голосовых вызовов (Telegram, WhatsApp), онлайн-игр и DNS через UDP-туннель.
- **Встроенный диагностический пинг-тестер**: Прямая проверка SOCKS5-рукопожатия из приложения с замером точной задержки (RTT) в миллисекундах.
- **Удобный выбор приложений**: Поиск установленных приложений по названию и пакету, фильтры «Все» / «Выбранные», быстрые кнопки «Выбрать все» / «Снять».
- **Энергоэффективность и стабильность**: Оптимальный MTU 1400 (предотвращает фрагментацию и зависания пакетов в сетях 4G/5G LTE), адаптивный опрос статистики трафика и отсутствие утечек памяти при скролле списков.
- **Современный интерфейс**: Jetpack Compose, Material 3, швейцарский чистый дизайн, соответствие стандартам доступности **WCAG 2.2 AAA** и поддержка TalkBack.

---

## Архитектура проекта

- **Язык**: Kotlin 2.2 + C (JNI)
- **UI**: Jetpack Compose (Material 3)
- **Архитектура**: MVVM + Unidirectional Data Flow (StateFlow / Coroutines)
- **Сетевой движок**: `VpnService` + `com.zaneschepke:hevtunnel` (`hev-socks5-tunnel`)
- **Минимальная версия Android**: Android 8.0 (API 26+)
- **Целевая версия Android**: Android 15 (API 35) / Android 16 (API 36)

## Установка

Скачайте скомпилированный APK из раздела [Releases](https://github.com/kotpers67-spec/socks5-proxy-android/releases) и установите его на Android-устройство:

```bash
adb install -r Socks5Proxy.apk
```

## Сборка из исходников

```bash
# Клонирование репозитория
git clone https://github.com/kotpers67-spec/socks5-proxy-android.git
cd socks5-proxy-android

# Сборка Debug APK
./gradlew assembleDebug

# Готовый APK будет расположен в:
# app/build/outputs/apk/debug/app-debug.apk
```
